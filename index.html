How to export from OOTP

Important: After Write report to disk, wait until the HTML page has fully finished loading in your browser before you Save as / upload. Large lists can take a while — if you save too early, players at the bottom will be missing from Hector.

Player List (required)

Create a custom Player List view with the columns below, then export to disk as HTML (StatsPlus / in-game HTML export). Column order can vary — Hector matches by header name.

  1. League menu → Transactions

  2. Players → Player List — include minor leaguers and free agents as shown (retirees / international complex off unless you need them).

  3. VIEW → Customize… to build the Hector export view.

  4. GENERAL — identity columns (ORG, POS, Name, Age, Bats/Throws, OVR/POT, Injury Prone, National / Local Popularity, Personality Type, etc.).

  5. BATTING RATINGS — Contact, Gap, Power, Eye, K’s and potentials.

  6. PITCHING RATINGS — Stuff / Movement / Control, arsenal grades + potentials, Pitches, Velocity, Stamina, Ground/Fly, Hold.

  7. FIELDING RATINGS — catcher / infield / outfield tools and position fielding grades.

  8. BATTING STATS — G, rate stats, wRC+, WAR, etc.

  9. PITCHING STATS — IP, ERA+, FIP, WAR, rWAR, HLD/SV, etc.

  10. FIELDING STATS — at least E, ZR, and CERA.

  11. MISC. INFO — Salary / years / contract value fields and Scout Acc.

  12. VIEW → Save View… so you can reuse this column set next time.

  13. Name the view (e.g. Hector All) and click Save as Global.

  14. REPORT → Write report to disk to open the HTML export in your browser.

    Wait for the page to finish loading completely before the next step — otherwise the saved file can be missing players.

  15. Once loading is done, right-click → Save as…

  16. Save as Player List.html (Webpage, Complete / HTML) — then upload that file above.

Draft Class (optional)

Same columns as Player List — reuse the Hector All view you already saved (no need to rebuild Customize View). Export the draft pool as HTML for the Draft tab (potential-heavy scoring: potential ×1.5, current ×0.9).

  1. League menu → Rookie Draft

  2. Open the DRAFT POOL tab.

  3. VIEW → Hector All (or whatever you named the Player List view) — same columns, no re-customize needed.

  4. REPORT → Write report to disk to open the HTML in your browser.

    Wait for the page to finish loading completely before Save as — otherwise the draft file can be missing players.

  5. Once loading is done, right-click → Save as…

  6. Save as Draft List.html (Webpage, Complete / HTML) — then upload that file in Draft Class above.

Team List (optional)

Standings + park factors for Teams and League Analysis (join on Abbr ↔ player ORG). Talent / WAR on League Analysis still comes from the Player List, not Team List WAR columns.

  1. League menu → Statistics

  2. TEAM STATISTICS & INFO → SORTABLE STATS

  3. VIEW → Customize… (save as e.g. hector team stats when done).

  4. GENERAL — Team Name, Abbr, Park, League, Sub-League, Division, Nation.

  5. RECORD — Games, Wins, Losses, PCT, Streak, Magic, POS, GB, Clinch.

  6. HISTORY — Last Wins, Last Losses, Last PCT (exports as lyW / lyL / ly%).

  7. MISC INFO — park factors: PF, PF AVG, AVG L/R, PF HR, HR L/R, PF D, PF T.

  8. VIEW → Save View… so you can reuse this team stats view next time.

  9. Name the view (e.g. hector team stats) and click Save as Global.

  10. Report → Write report to disk to open the HTML in your browser.

    Wait for the page to finish loading completely before Save as — otherwise clubs can be missing from the file.

  11. Once loading is done, right-click → Save as… and save as Team List.html (Webpage, Complete / HTML) — then upload that file above.
